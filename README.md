# UNET-Chest-X-Ray-Segmentation-_-Tri-Attention-_-Transfer-Learning-_-GRAD-CAM-_-Attention-Mapping
This project presents a compact Tri-Attention Transfer U-Net framework for robust lung segmentation in chest X-ray images. It integrates ResNet50-based transfer learning with channel, spatial, and crisscross attention modules to improve segmentation accuracy and generalization across Montgomery, Shenzhen, and Darwin datasets. The framework also supports Grad-CAM-based interpretability and evaluates real-time edge feasibility for practical clinical deployment.
